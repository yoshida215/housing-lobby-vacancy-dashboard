# 空室業務ダッシュボード（共有保存版）

空室・原状回復・入居率・巡回を1画面で扱う社内ツール。試作版（`../vacancy-operations-prototype`・ChatGPT Sites公開）とは別フォルダで、試作版は変更していない。

## 構成

```
GitHub Pages（docs/）  ──fetch──▶  Google Apps Script（gas/Code.gs）  ──▶  Asana API
 画面・集計・住所/ルート            Asanaトークン保管・合言葉チェック        【空室一覧】【14日ルール】
```

- **巡回記録の正本＝Asanaの空室タスクのコメント**（先頭が「【巡回記録】YYYY-MM-DD」）。Asana上で同じ書式のコメントを手入力しても、部屋ページを開いた時点で履歴に取り込まれる。
- 一覧の「前回／次回巡回」はGASのスクリプトプロパティ（`L_<タスクGID>`）にある索引を使う。ずれた場合はGASエディタで `rebuildPatrolIndex` を実行。
- 空室データはGASがAsana【募集中】をセクション単位で最終ページまで取得（検索APIは使わない）。未完了・親タスクのみ、GIDで重複排除。10分キャッシュ。URLに `?refresh=1` で即時再取得。
- 管理戸数は月ごとに画面（入居率・空室タブ下部）から登録（`M_YYYY-MM`）。当月分が無い月は入居率を「更新待ち」と表示し、前月値を流用しない。
- 現地確認12項目（patrol-items.js と CFG.patrolFields で定義。のぼり等5項目＋室内清掃・共用部清掃・ポストシール・カラーコーン・芳香剤補充・畳カビ確認・電子キー電池確認）と鍵種別（既存項目）を連動。不備の項目は写真を対応タスクへ、その他の写真は巡回確認へ添付（端末で長辺1600pxに縮小）。旧記述：現地確認5項目は【空室一覧】のカスタム項目（のぼり／募集看板／管理看板／ウェルカムセット／ステージング：あり・なし）と連動。巡回登録時に値を更新し、部屋ページはその値を初期チェックにする。導入はGASエディタで `checkPatrolFields`（確認のみ）→ `setupPatrolFields`（追加）を手動実行。
- 巡回記録は物件タスク直下のサブタスク「巡回確認（YYYY-MM-DD）」の説明欄に保存。「なし」の項目（ステージング以外）はその中に「○○を設置」を作成（未完了の同名があれば作らない）。次の巡回で「あり」なら自動で完了、中が全部完了した巡回確認も完了。旧形式（コメント／直下の【巡回】サブタスク）も読み取る。
- 管理戸数は非公開（GASプロパティ `M_YYYY-MM`）。画面へは率のみ返す。正本は全体会議資料「○月度（○月実績）」→実績月で登録。
- 14日ルール完了の表示は読み取りのみ。空室状況の変更・メンションコメントは実装していない（従来どおりdry-run→承認後に別途実行）。

## 安全設計

- Asanaトークンは画面・リポジトリに置かない（GASのスクリプトプロパティのみ）。
- 閲覧はログイン不要。巡回登録は「巡回登録の合言葉」、管理戸数は「管理用の合言葉」が必要。合言葉は各端末のブラウザに記憶される（共有端末では注意）。
- 登録前に「確認画面」でAsanaへ書き込むコメント本文を表示し、確定ボタンで初めて書き込む。
- 登録ごとに一意のIDをコメント末尾に付け、同じIDがあれば再投稿しない（二重送信対策）。
- 書き込み先は【空室一覧】プロジェクトに属するタスクに限定。
- コメントの投稿者はトークン発行者のアカウントになる。実際の巡回者はコメント内「担当：」に記録。

## セットアップ（初回のみ・ユーザー作業）

1. **Asanaトークン発行**：Asana → マイ設定 → アプリ → 開発者アプリ → 個人アクセストークン。
2. **GASプロジェクト作成**：script.google.com → 新しいプロジェクト → `gas/Code.gs` の内容を貼り付け。プロジェクトの設定で「appsscript.json をエディタで表示」をオンにし、`gas/appsscript.json` を貼り付け。
3. **スクリプトプロパティ**（プロジェクトの設定 → スクリプト プロパティ）：
   - `ASANA_TOKEN` … 1のトークン
   - `EDIT_PASSCODE` … 巡回担当者に共有する合言葉
   - `ADMIN_PASSCODE` … 管理戸数を登録する人だけの合言葉
   - `HISTORY_SHEET_ID` … 任意。日次入居率を記録するスプレッドシートのID
4. **デプロイ**：デプロイ → 新しいデプロイ → 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」。発行されたURL（…/exec）を `docs/config.js` の `apiUrl` に設定。
5. 動作確認：`<URL>?action=ping` が `{"ok":true}` を返すこと。
6. 任意：GASエディタで `installDailyTrigger` を1回実行 → 毎日17:30に入居率をシートへ記録。

コード修正時は「デプロイを管理」→ 既存デプロイを編集 → 新バージョン、でURLを変えずに更新する。
